# Marvel Strike Force Planning

Trackers for events, resources and character builds.

## Files

- **Event_Tracker.xlsx** is the main tracker. Its tabs:
  - **Build Priority**: which characters to build next and why
  - **Tower Roster**: Tower Challenger III characters for the Kyln tower
  - **Kyln Tower**: Kyln tower milestones
  - **Resources**: gold, ions and training materials
  - **Dailies**: daily checklist

Yellow cells are the ones to fill in.
